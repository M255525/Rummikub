# 數字牌接龍

一款以中高齡使用者為設計核心的數字牌組合線上桌遊，純前端實作，無需安裝，開啟即玩。

---

## 快速開始

直接用瀏覽器開啟 `數字牌接龍.html`，即可開始遊戲。無需網路、無需安裝任何套件。

---

## 遊戲規則

### 牌組組成（共 106 張）

| 類型 | 說明 |
|------|------|
| 數字牌 | 紅、藍、橘、黑 四種顏色，每色數字 1–13，各兩組，共 104 張 |
| 百搭牌 | 2 張，可代替任意一張牌使用 |

### 合法牌型

- **組合 (Group)**：3 或 4 張相同數字、不同顏色的牌（例如：紅7、藍7、橘7）
- **順子 (Run)**：3 張以上同色、數字連續的牌（例如：黑9、黑10、黑11）

### 首次出牌規則

每位玩家第一次出牌，所有新放出的牌點數總和必須達到 **30 分以上**。之後的回合則無此限制。

### 輪流與抽牌

若當回合無法出牌，需從牌堆摸一張牌並結束本回合。

### 勝負判定

- 最先出完所有手牌者獲勝
- 若牌堆已空仍無人出完，手牌點數最少者獲勝

---

## 操作方式

### 出牌流程

1. 點選手牌中的牌（出現金色邊框代表已選取）
2. 點選牌桌上的組合列 **「＋加入此組」**，將牌加入既有組合
3. 或點選 **「新增一組」**，建立全新的牌型
4. 也可以直接將手牌**拖拉**到牌桌上
5. 排列完成後點 **「確認出牌」** 提交

### 各按鈕說明

| 按鈕 | 功能 |
|------|------|
| 確認出牌 | 驗證並提交本回合的出牌（不合法會提示原因） |
| 摸牌 | 從牌堆補一張牌，結束本回合（無法出牌時使用） |
| 取消 | 撤回本回合所有操作，回到回合開始狀態 |
| 排列手牌 | 將手牌依顏色與數字排序 |

---

## 設定選項

點右上角 **「⚙ 設定」** 開啟設定面板：

| 設定 | 說明 |
|------|------|
| 放大字體 | 文字與牌面放大，適合視力需求較高的使用者 |
| 高對比模式 | 提高顏色對比，改善辨識度 |
| 電腦玩家數 | 選擇 1、2 或 3 位電腦對手 |
| 重新開始 | 捨棄目前進度，重新開一局 |

---

## 介面特色（中高齡友善設計）

- 文字最小 18px，放大模式 22px
- 所有按鈕最小點擊區域 44×44px
- 每個操作都有中文文字說明，不依賴單純圖示
- 不設讀秒倒數，玩家可從容思考
- 無效出牌即時提示原因（紅色邊框＋說明文字）
- 一鍵取消本回合所有操作，誤觸不怕

---

## 響應式版面（RWD）

| 裝置 | 寬度 | 調整 |
|------|------|------|
| 手機 | < 600px | 牌面縮小至 40×52px，精簡間距 |
| 平板 | 600–980px | 標準版面 |
| 桌機 | > 980px | 牌面放大至 56×74px，寬裕間距 |

## 已知限制（MVP 階段）

- 目前為**單機版**，僅支援對戰電腦，尚未支援多人連線
- AI 邏輯為基礎策略，不會進行複雜的牌桌重新排列
- 百搭牌（Joker）在 AI 手中目前不會被主動使用
- 尚未加入語音提示功能
