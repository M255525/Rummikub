# 修改數字牌接龍

單一檔案 vanilla HTML/CSS/JS，無相依、無建置、無測試。修改後以瀏覽器開啟驗證即可。

## 兩個版本必須同步

- `數字牌接龍.html` — 遊戲本體。
- `數字牌接龍-GoogleSites嵌入用.html` — Google Sites 嵌入變體。

改動玩法或介面時，**兩檔都要一起更新**（或由主檔重新產生嵌入版）。`一鍵複製-貼到GoogleSites.bat` 可把嵌入版內容複製到剪貼簿供貼上 Google Sites。

## 中高齡友善約束（勿破壞）

這是本專案的核心設計，不是可選樣式：
- 文字最小 18px（放大模式 22px）；按鈕點擊區 ≥44×44px。
- 每個操作皆有中文文字說明，不使用純圖示。
- 不設讀秒倒數；無效出牌即時以紅框＋文字提示原因；可一鍵取消整回合。
- 保留高對比模式與 RWD 斷點（手機 <600px／平板 600–980px／桌機 >980px）、滑鼠拖拉與觸控點選並存。

## 遊戲規則（改規則時須一致）

106 張牌（紅／藍／橘／黑 ×1–13 各兩組＝104，＋百搭 2）；合法牌型 Group（3–4 張同數字不同色）與 Run（3 張以上同色連號）；首出 ≥30 分；電腦對手 1–3 位（基礎 AI，不重排牌桌、不主動用百搭）。
